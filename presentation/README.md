# Préparer une présentation

Ce dossier contient un modèle réutilisable pour préparer des présentations en Markdown.

## Créer une présentation

1. Copie `modele.md` et renomme la copie, par exemple `mon-sujet.md`.
2. Remplace les indications entre crochets par ton contenu.
3. Garde une idée principale par diapositive. Les lignes `---` séparent les diapositives.
4. Supprime les sections dont tu n'as pas besoin et ajoute des diapositives en copiant le format.

Le fichier est du Markdown simple : tu peux le lire et le modifier dans un éditeur de texte, ou le convertir avec un outil compatible Markdown.
